# HalloHome — Usage

## Prerequisites

- Node.js >= 20
- pnpm >= 9
- Rust >= 1.78 (with `rustfmt` and `clippy`)
- Linux system deps: `libgtk-3-dev`, `libwebkit2gtk-4.1-dev`, `libappindicator3-dev`, `librsvg2-dev`, `patchelf`
- macOS / Windows: Tauri v2 prerequisites per https://v2.tauri.app/start/prerequisites/

## Install

Clone and install:

```bash
git clone https://github.com/ramaekayudha/HalloHome.git
cd HalloHome
pnpm install
```

This generates `pnpm-lock.yaml`. The first `cargo build` generates `Cargo.lock`. Both must be committed.

## Fonts — user must provide

Place these files in `src/ui/public/fonts/`:

- `Lora-Regular.woff2`
- `Lora-Medium.woff2`
- `Lora-Bold.woff2`
- `Lora-Italic.woff2`

`OFL.txt` is already included in that folder.

Source: Google Fonts — Lora (SIL OFL 1.1, https://fonts.google.com/specimen/Lora).

No other fonts are permitted.

## Verify (mandatory before release)

```bash
pnpm verify
```

Runs in order:

1. `pnpm logo` — generates brand PNGs
2. `pnpm --filter @hallohome/ui build` — frontend dist
3. `cargo fmt --all -- --check`
4. `cargo clippy --workspace --all-targets -- -D warnings`
5. `cargo test --workspace`
6. `cargo build --release --workspace`
7. `pnpm --filter @hallohome/ui typecheck`
8. `pnpm --filter @hallohome/ui lint`

All must be GREEN. Any failure must be fixed before release.

## Manual test (must be GREEN)

After `pnpm tauri dev` (from `src/tauri`) or equivalent:

- App window opens.
- Hero logo centered.
- Footer shows exactly one line: `© Copyright {year} HalloHome | Terms of Use | License`.
- Theme toggle switches light/dark and persists across restart.
- Hamburger opens dropdown; items are user-pickable.
- All text uses Lora only.
- Brand PNGs present in `src/ui/public/brand/`.

## Release

```bash
pnpm bump
```

Runs `pnpm verify`, computes next version (carry base-10 per segment), updates all manifests and README badge, regenerates `scripts/restore.md`, commits, tags, and pushes.

Version carry: `0.0.9 -> 0.1.0`, `0.9.9 -> 1.0.0`.

## Restore snapshot

```bash
pnpm restore
```

Regenerates `scripts/restore.md` — full source snapshot of essential files. Binary assets are excluded. Overwritten on each run.

## Brand assets

```bash
pnpm logo
```

Writes PNGs into `src/ui/public/brand/`:

- `favicon-32.png`
- `apple-touch-180.png`
- `logo-hero-512.png`
- `logo.png`

## Lockfiles — must be committed

Generated on first run, then committed:

- `Cargo.lock`
- `pnpm-lock.yaml`

## Excluded from git

- `target/`, `node_modules/`, `dist/`, `build/`
- `src/ui/public/brand/` (regenerated by `pnpm logo`)
- `.env*`, logs, OS files
